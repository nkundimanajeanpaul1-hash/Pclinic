1. Back up your existing Pclinic project.
2. Extract this ZIP.
3. Copy every extracted file into the root of your existing Pclinic project.
4. Keep the same folder structure (especially functions/ and functions/test/).
5. Approve overwrite/replace when prompted.
6. If you installed an earlier bundle, replace the files again. The current
   version adds the server-authoritative specimen accession/rejection function.
