WHAT YOU GET
------------
Doctor dashboard → Imaging Results (imaging-results.html) is now a full-page
workstation laid out like your screenshot, under the PClinic header and the
patient identification bar:

  left    DICOM EXPLORER — Search patient…, Search tags…, Studies / DICOM tags
          tabs, Patient → Study (state pill) → thumbnails (drag a thumbnail
          into any viewport). Right-click a thumbnail (radiology) → remove.
  top     TOOL BAR — Explorer · Export ▾ · Window/Level · Pan · Zoom · + − ·
          Fit · Layout ▾ · Sync · Reset · Ruler · Angle · ROI ▾ (rectangle,
          ellipse, freehand, bidirectional, Cobb, W/L-from-region) · Probe ·
          Arrow/text · Delete ▾ · Magnify · Rotate ▾ (rotate 90/180, flip H/V,
          free rotate) · Flip · Invert · Presets ▾ (per-modality W/L presets +
          colour maps) · Cine · ‹ › · Full screen  (+ Upload for radiology)
  centre  "Image Viewer" tab, 1×1 … 2×3 viewports, corner overlays (patient /
          ID / DOB-sex-age · study / date / modality / institution / series ·
          Frame / Zoom / Window-Level · matrix / pixel spacing / file / uploader),
          scale bar (mm/cm or pix), orientation letters L/R/A/P/H/F that follow
          rotation and flips, PRELIMINARY banner until a report is signed,
          cine bar (play/pause, slider, fps), double-click = maximise.
  right   vertical tabs Display · Image Tools · Draw & Measure · Study Info ·
          Report (findings, impression, addenda, critical flag, signer, Print/PDF).
  bottom  status bar (patient · study · file · tool · live pixel value / HU);
          the former report list is kept underneath in a "Radiology reports"
          drawer (count badge, Print / PDF, acknowledge critical, "Show images
          in workstation").

  Every tool works on JPEG/PNG/WebP AND on DICOM: uncompressed, RLE, JPEG
  baseline, JPEG-LS, JPEG 2000, HTJ2K, multi-frame (cine). CT values read
  in HU; measurements in mm / mm² when the file carries pixel spacing, else
  px / px². Keyboard: ← → frames/images, + − 0 zoom, R/⇧R rotate, H/V flip,
  I invert, F full screen, Space cine, Del delete selected, W/P/Z/L/A/M tools,
  Esc close (modal). Touch: one finger = tool, pinch = zoom, two fingers = pan.
  Phone/tablet: explorer and side panels become drawers; tool bar scrolls.

  One patient truth: identification-bar Find/Clear ⇄ explorer patient search
  ⇄ ?patient= URL ⇄ workstation, exactly as on the radiology dashboard.
  Doctors see images as soon as radiology uploads them (marked PRELIMINARY,
  decision D1); doctors are read-only; radiology's "Open DICOM to add radiology
  result" opens the SAME workstation as a modal with Upload/Remove (D3).

  Saving measurements / key images / notes to the common server is Zip B
  (the Draw & Measure panel says so); export a screenshot meanwhile.

DEPLOY — in this order
----------------------
  1. Extract the zip over the project folder (overwrite). Commit + push.
  2. Terminal in the project folder:
        cd functions && npm install && cd ..
        firebase deploy --only functions          (radiologyMediaSign fallback)
        firebase deploy --only hosting            (pages + vendor/ + new CSP)
  3. Bucket CORS (ONE time; needed so the browser may READ the image bytes
     for DICOM decoding and measurements — without it JPEG/PNG still show as
     plain pictures but DICOM cannot be decoded):
        gsutil cors set cors.json gs://pclinic-20d81.firebasestorage.app
     No gsutil? Open https://console.cloud.google.com/?cloudshell=true
     (project pclinic-20d81), click "Open editor", upload cors.json, then run
     the same command in the Cloud Shell terminal.
  4. If not done yet: IAM → compute service account → add role
     "Service Account Token Creator" (or rely on the token fallback from step 2).
  5. Hard refresh (Cmd/Ctrl+Shift+R). Doctor: select patient → Imaging Results.
     Radiology: select patient → Open DICOM to add radiology result.
